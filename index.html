Frequently Asked Questions

What is Scott AI?
Scott AI is an agent-native alignment platform. It gives development teams the tools to plan, align, and delegate to AI coding agents — so agents execute on what you actually meant to build. Every planspace has full reasoning context ready to hand off to any coding agent through CLI or integrations.
What coding agents does Scott work with?
Scott AI works with all major coding agents including Cursor, Claude Code, GitHub Copilot, OpenAI Codex, Cline, Windsurf, Kiro, and more. Any agent that can consume context from a CLI or API integration can use Scott planspaces.
How is this different from Google Docs or Notion?
Google Docs and Notion are built for human-to-human collaboration. Scott is built for human-to-agent handoff. Planspaces are grounded in your actual codebase and knowledge sources, structured for agent consumption, and designed to minimize token waste during execution.
Do I need to change my development workflow?
No. Scott plugs into your existing workflow. You keep using the coding agents and tools you already use — Scott adds the alignment layer before execution. Think of it as a pre-flight checklist that runs before your agent takes over.
